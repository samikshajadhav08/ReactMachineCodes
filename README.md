# 🚀 30 Days React Machine Coding

A 30-day challenge to improve **React.js, JavaScript, UI development, and problem-solving skills** by building one project every day.

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## 🎯 Goals

- Strengthen React fundamentals
- Practice Hooks and state management
- Build reusable components
- Improve JavaScript skills
- Prepare for React machine coding interviews
- Maintain a consistent coding streak

## ▶️ Run Locally

```bash
npm install
npm run dev
```
